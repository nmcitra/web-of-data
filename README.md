# Web of Data

**Canonical copies of the essays of Chris Perkins.**

Released each year on **November 4th**, the anniversary of
[*Web of Data*](https://medium.com/@chrisperkins505/web-of-data-4e4272c7031c)
(2024) — the ur-text this archive is named for.

---

## Why this exists

Every essay here was published somewhere else first. That somewhere is a record
I do not control: it can be edited, rate-limited, paywalled, reorganized, or
taken down, and none of those events would ask me first.

That is the same problem the essays are about. A representation of a thing is not
the thing, the two drift apart at different rates, and whoever holds the
representation decides what it says. The fix is not to stop publishing on
platforms. It is to keep a copy whose provenance I can point at — dated,
diffable, and mine.

So this repository is the canonical version. The platform links are companions.

## What is here

```
essays/
  YYYY-MM-DD-slug/
    index.md      the canonical text
    meta.yml      title, dates, platform links, sources, license
    images/       cover art and figures as published
```

Each essay directory is dated by first publication. Git history carries the rest:
when a text changed, and to what.

## Schedule

Release cadence (annual, November 4th) and per-essay lifecycle dates (`date_published`, `date_revised`, `date_edited`, `date_canonical`) live in [`SCHEDULE.md`](SCHEDULE.md).

## Migration status

The back catalogue is being moved by hand, oldest obligations first, not in bulk.
An essay appears here when it has been checked — not when it has been scraped.
`INDEX.md` lists what has landed.

## Corrections

If something here is wrong, open an issue. Corrections are made in place with the
change visible in history, never silently. A published essay is not edited for
style; it is corrected for fact, and the correction is legible.
